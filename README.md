# MYKO Coffee

Особистий веб-проект інтернет-магазину та панелі управління замовленнями для кав'ярні MYKO Coffee.

---

## Основні можливості

- **Вітрина та меню напоїв**: Вибір кави, розмірів та додатків із динамічним розрахунком вартості.
- **Інтерактивний кошик**: Додавання товарів, зміна кількості та швидке оформлення замовлення.
- **Побажання клієнтів**: Підтримка коментарів до замовлення (помол зерна, додатковий сироп тощо).
- **Адмін-панель**: Панель моніторингу замовлень для бариста з можливістю зміни статусів (Нове -> Готується -> Готово -> Видано), відображенням каси та аналітики.
- **Telegram-бот**: Автоматичні сповіщення про нові замовлення у Telegram-чат.

---

## Технологічний стек

- **Frontend**: HTML5, CSS3, JavaScript (ES6+).
- **Backend**: Node.js, Express.js.
- **Тестування**: Jest (48 unit-тестів).
