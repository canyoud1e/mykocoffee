# ☕ MYKO Coffee — Особистий проект

Особистий веб-проект інтернет-магазину та панелі управління замовленнями для кав'ярні **MYKO Coffee**.

---

## 📌 Особливості проекту

- ☕ **Вітрина та меню напоїв**: Зручний вибір кави, розмірів та додатків із динамічним розрахунком вартістей.
- 🛒 **Інтерактивний кошик**: Додавання товарів, зміна кількості та швидке оформлення замовлення.
- 💬 **Побажання клієнтів**: Підтримка коментарів до замовлення (наприклад, помол зерна, додатковий цукровий сироп тощо).
- 📋 **Адмін-панель**: Панель моніторингу замовлень для бариста — зміна статусів (`Нове` ➔ `Готується` ➔ `Готово` ➔ `Видано`), відображення каси та аналітики.
- 🤖 **Telegram-бот**: Автоматичне миттєве сповіщення про нові замовлення у Telegram-чат.

---

## 🛠 Технології

- **Frontend**: HTML5, Vanilla CSS3 (Custom Properties, Flexbox/Grid), ES6+ JavaScript.
- **Backend**: Node.js, Express.js.
- **Тестування**: Jest (48 автоматичних unit-тестів бізнес-логіки).

---

## 🚀 Запуск проекту

1. **Клонувати репозиторій**:
   ```bash
   git clone https://github.com/canyoud1e/mykocoffee.git
   cd mykocoffee
   ```

2. **Встановити залежності**:
   ```bash
   npm install
   ```

3. **Запустити сервер локально**:
   ```bash
   npm start
   ```
   Сайт буде доступний за адресою: `http://localhost:3000`  
   Адмін-панель: `http://localhost:3000/admin.html` (Пароль за замовчуванням: `admin`)

4. **Запустити автоматичні тести**:
   ```bash
   npm test
   ```
